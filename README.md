# Python Code 🐍

A collection of Python practice programs created while learning and strengthening the fundamentals of Python.

This repository is mainly focused on practicing Python syntax, core concepts, operators, data types, conditions, loops, and functions through simple hands-on examples.

## 📚 Topics Covered

| File                         | Topic                                                      |
| ---------------------------- | ---------------------------------------------------------- |
| `python-basics.py`           | Python syntax, variables, input/output, and basic concepts |
| `arithmatical-operations.py` | Arithmetic operators and mathematical operations           |
| `comparison-operator.py`     | Comparison operators and comparisons                       |
| `logical-operators.py`       | Logical operators such as `and`, `or`, and `not`           |
| `conditions.py`              | Conditional statements using `if`, `elif`, and `else`      |
| `list-data-operation.py`     | Lists and common list operations                           |
| `dictionary-data-type.py`    | Dictionaries and dictionary operations                     |
| `loop-data.py`               | Loops and iteration                                        |
| `function.py`                | Functions, parameters, arguments, and return values        |

## 🚀 Getting Started

Make sure Python 3 is installed on your system.

Check the Python version:

```bash
python3 --version
```

Clone the repository:

```bash
git clone https://github.com/tanahmeeedsx/python-code.git
```

Navigate to the repository:

```bash
cd python-code
```

Run any Python file:

```bash
python3 python-basics.py
```

For example:

```bash
python3 conditions.py
```
